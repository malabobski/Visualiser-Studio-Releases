# Visualiser Studio releases

A place to hang out with your music.

This public repository hosts official Windows installers, change notes and automatic-update files. Application source code is maintained separately.

- [Download the latest release](https://github.com/malabobski/Visualiser-Studio-Releases/releases/latest)
- [Visit the website](https://malchim.malabobski.workers.dev/)

Installed apps check for updates and let you choose when to restart. Download the Setup .exe for a manual installation; the other assets are used by the updater.
